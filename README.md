# Мини-синхронизатор заявок

Сервис забирает сырые заявки с `https://test.ooobs.ru/api/orders`, нормализует телефоны к `+7XXXXXXXXXX`, отбрасывает номера, которые не сводятся к 11 цифрам, и дедуплицирует по телефону.

При дубле остаётся запись с большим `amount`. Если суммы равны — более поздняя по `created_at`.

Результат: `GET /result`

```json
{
  "clients": [
    { "name": "...", "phone": "+79991234567", "email": "...", "amount": 5000 }
  ],
  "stats": {
    "received": 0,
    "unique": 0,
    "duplicates_merged": 0,
    "invalid_dropped": 0
  }
}
```

Повторный запрос ничего не сохраняет и не размножает записи: ответ каждый раз заново считается из источника.

Секретов нет. Адрес источника можно переопределить переменной `ORDERS_URL`.

```bash
npm test
npm start
```
